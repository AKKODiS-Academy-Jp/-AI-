## 構築演習③エージェントのパラメータ
パラメータとは、システムの挙動を決める、調整用の設定値です。
Agent Builderでは次のパラメータを入力して、挙動を制御します。
　  
1. アイコン  
エージェントのアイコンを表示します。
クリックして、生成、参照、アップロードのいずれかの手法でアイコンを選択します。
2. エージェント名  
エージェントの表示名を記載します。
3. 説明  
エージェントの概要や使い方を記載します。
<img width="992" height="180" alt="スクリーンショット 2026-06-01 195548" src="https://github.com/user-attachments/assets/befc5fcf-14ea-43ef-8dbe-646a37ea5bcd" />
　  
4. 指示  
エージェントの挙動を制御するプロンプトを記載します。  
Agent Builderでは、この指示に書かれたプロンプトが、生成挙動のすべてを制御します。
Agent Builderのパラメータで、もっとも重要かつ影響が大きい部分です。
動作試験を繰り返し、希望する挙動になるようこのパラメータを調整しましょう。


<img width="1023" height="444" alt="スクリーンショット 2026-06-01 200056" src="https://github.com/user-attachments/assets/7426a446-e19b-44bb-81be-7d940c85a982" />
　  
6. ナレッジ  
エージェントが参照するデータを制御します。
- ファイル、会議、チャット、メール、Webサイトを追加する
  - エージェントに直接参照させたい独自のデータ（社内資料や特定のWebページなど）を追加する場所です。  
  - アイコンの意味: 左から SharePoint、Teams、Outlook、一般のWebサイト を指しており、これらと連携してファイルやテキストデータをドロップ、またはURL入力で追加できます。  
- すべてのWebサイトを検索します  
  - Bingなどの検索エンジンを使って、インターネット上のあらゆる公開情報をオープンに検索して回答に利用するかどうかの設定です。  
  - ステータス: デフォルトは「オフ」になっています。  
  - 特定のサイトだけに制限したい場合は、上の入力欄にURLを入れます。  
- 指定したソースのみを使用する  
  - エージェントの回答ソースを、上記で明示的に追加したファイルやWebサイト「だけ」に厳密に制限する設定です。    
  AIが勝手に一般的な知識（ハルシネーションなど）で答えるのを防ぎます。  
  - ステータス: デフォルトは「オン」になっており、セキュリティや正確性を重視したガバナンスの効いた状態です。  
- 組織図とプロフィール情報を参照する  
  - 社内のMicrosoft 365（Microsoft Graph）に登録されている、社員の組織図やプロフィール情報を参照して回答に活かすかどうかの設定です。  
  - ステータス: デフォルトは「オフ」になっています。オンにすると「〇〇さんの上司は誰？」といった社内特有の質問に答えられるようになります。
