## 構築演習③エージェントのパラメータ
パラメータとは、システムの挙動を決める、調整用の設定値です。
Agent Builderでは次のパラメータを入力して、挙動を制御します。
　  
1. アイコン  
エージェントのアイコンを表示します。
クリックして、生成、参照、アップロードのいずれかの手法でアイコンを選択します。
2. エージェント名  
エージェントの表示名を記載します。
3. 説明  
エージェントの概要や使い方を記載します。

5. 指示  
エージェントの挙動を制御するプロンプトを記載します。　    
Agent Builderでは、この指示に書かれたプロンプトが、生成挙動のすべてを制御します。　  
Agent Builderのパラメータで、もっとも重要かつ影響が大きい部分です。　  
動作試験を繰り返し、希望する挙動になるようこのパラメータを調整しましょう。

7. ナレッジ　    
エージェントが参照するデータを制御します。　  
- ファイル、会議、チャット、メール、Webサイトを追加する
  - エージェントに直接参照させたい独自のデータ（社内資料や特定のWebページなど）を追加する場所です。  　  
  - アイコンの意味: 左から SharePoint、Teams、Outlook、一般のWebサイト を指しており、これらと連携してファイルやテキストデータをドロップ、またはURL入力で追加できます。  　  
- すべてのWebサイトを検索します  　  
  - Bingなどの検索エンジンを使って、インターネット上のあらゆる公開情報をオープンに検索して回答に利用するかどうかの設定です。  　  
  - ステータス: デフォルトは「オフ」になっています。  　  
  - 特定のサイトだけに制限したい場合は、上の入力欄にURLを入れます。  　  
- 指定したソースのみを使用する  　  
  - エージェントの回答ソースを、上記で明示的に追加したファイルやWebサイト「だけ」に厳密に制限する設定です。    　  
  AIが勝手に一般的な知識（ハルシネーションなど）で答えるのを防ぎます。  　  
  - ステータス: デフォルトは「オン」になっており、セキュリティや正確性を重視したガバナンスの効いた状態です。  　  
- 組織図とプロフィール情報を参照する  　  
  - 社内のMicrosoft 365（Microsoft Graph）に登録されている、社員の組織図やプロフィール情報を参照して回答に活かすかどうかの設定です。  　  
  - ステータス: デフォルトは「オフ」になっています。オンにすると「〇〇さんの上司は誰？」といった社内特有の質問に答えられるようになります。

6. 機能  
- ドキュメント、グラフ、コードを作成します
  - 概要: エージェントに高度なデータ処理や、各種Officeファイルの生成機能を持たせる設定です。
  - できること: * データの分析、数学的な方程式のグラフ化
  - プログラミングのコードスニペット（断片）の生成

- Word、Excel、PowerPoint ファイルの直接作成
  - （アイコンが表示されている通り、成果物としてファイルをダウンロードできるようになります）
  - デフォルト: オン
  - ユーザーが「このデータをExcelにまとめて」と頼んだ際に、エージェントがファイルを作成して提供できるようになります。
    
- 画像を作成します
  - 画像生成AI（DALL-Eなど）を利用して、ユーザーの要望に応じたイラストや画像をその場で作成する機能です。
  - できること: ユーザープロンプトへの応答として、視覚的な補助となる画像やアート、図解などを生成します。
  - デフォルト: オン
  - 初期状態では有効です。  
  「～のイメージ画像を生成して」といったクリエイティブな要求に対応できるようになります。

7. 推奨プロンプト  
ユーザーがエージェントとのチャット画面を開いた際、最初にボタンとして表示される「よくある質問のサンプル」を登録・管理する場所です。

- パラメータの構成
  - タイトル（左側）:  
チャット画面にボタンとして表示される短いテキストです。ユーザーが一目で「これを質問できるんだ」とわかるように簡潔に記載します。
  - メッセージ（右側）:  
ユーザーがそのボタンをクリックした際、実際にエージェントへ送信される具体的なプロンプト（質問文）です。
  - ゴミ箱アイコン / グリップアイコン（右端）:  
登録したプロンプトの削除や、ドラッグ＆ドロップによる表示順序の入れ替え（並び替え）ができます。
  - 「＋ 推奨プロンプトを追加する」:
新しい質問の選択肢を自由に追加できます。
