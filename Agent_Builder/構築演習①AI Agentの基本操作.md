# Agent Builder 構築演習①
#### ※ 画面は2026年6月現在のものです。

この演習では、Agent Builder in Microsoft 365 Copilot を使用して
自律型AIエージェントを構築する手法を学習します。

## Agnet Builderについて
Agent Builderは、Microsoft 365 画面のメニューに組み込まれています。  
組織のアカウントでログインした状態でアクセスすると、利用可能なエージェントを参照できます。  
AgentはMicrosoftが作成して提供しているものと、組織で作成・公開されているものがあります。  

### エージェントへのアクセス
Microsoft 365 ホーム画面にて、左ペイン内の「エージェント」表記の下にいくつかのメニューが表示されます。
<img width="1908" height="938" alt="スクリーンショット 2026-06-01 185422" src="https://github.com/user-attachments/assets/966b5643-ce7b-4a3a-9220-5f3e4c2b2f30" />
1. 新しいエージェント  
エージェントの作成画面を開きます。
2. すべてのエージェント  
利用できるエージェントの一覧が開きます。
    
最近使ったエージェントや頻繁に使うエージェントがメニュー上部に表示されます。
表示するエージェントはピン止めで固定することもできます。

### すべてのエージェント  
すべてのエージェントメニューをクリックすると、右ペインにエージェントストア画面が開きます。  
<img width="1926" height="1025" alt="スクリーンショット 2026-06-01 190517" src="https://github.com/user-attachments/assets/9b4d5588-c5f7-4ffd-b203-1f2d66d4fa73" />
この画面では、次の機能を利用することができます。  
- エージェントを検索  
キーワードによるエージェント検索が実行できます。
機能や目的などで検索してみましょう。  
- エージェントのおすすめ  
推奨エージェントが表示されます。
表示を増やすドロップダウン矢印をクリックすると、表示数を増やせます。  
- Micorosoft製エージェントの紹介  
Microsoftが作成・提供している組み込み済みエージェントが表示されます。

画面をスクロールすると、その他の分類のエージェントが表示されます。  
利用したいものを探してみましょう。
